# Password Generator

A simple command-line password generator written in Python.

## Features

Generate secure random passwords
- Custom password length
- Include digits
- Include uppercase letters
- Include special characters
- Input validation

## Technologies

- Python 3
- secrets (Standard Library)

## Installation

Clone the repository

```bash
git clone https://github.com/AlpachaAlikhan/password-generator.git
```

Open the project

```bash
cd password-generator
```

Run

```bash
python main.py
```

## Example

```
Enter the desired password length: 16

Include numbers? (y/n): y

Include capital letters? (y/n): y

Include special characters? (y/n): y

Generated password:
T9@kaL7!zQ4nRwXp
```
